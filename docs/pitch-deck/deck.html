Four ideas that make GenAI safe to sell with.

Idea 1

A catalogue the AI can cite

Not a folder of PDFs: an offering graph of typed offerings, rate cards, results, rules and partners. Each item keeps the page it came from. Agents read only what a person confirmed.

Idea 2

The model never types a price

The Pricing role picks line IDs by function call. The Writer leaves placeholders. Code copies the price and does every sum, and cost never reaches a model.

Idea 3

No source, no sentence

Research claims are cut from Google Search grounding metadata in code. A sentence with no grounding is dropped and counted, never hidden, and links stay exactly as Google returned them.

Every block is marked AI, Calculated or a person. The model's output is kept untouched; people edit a working copy, locked at each gate. Trust you can see.

Scales by design

Stateless, queued, isolated
Every stage is a stateless run: read Firestore, write back, end. Nothing lives in memory between gates.
Cloud Run scales to zero and out on demand. Cloud Tasks queues long stages and retries safely.
Pipelines can move to their own worker service with a deploy change, not a rewrite.
Workspace isolation on every read. The browser never writes; rules deny it.
